# turkish-wifi-wordlist
Bu wordlist, yaklaşık 19 milyon parolayı içeren bir derlemedir. Dosya 250 mb yer kaplar zip dosyası halinde 50mb civvarında yer kaplar. İçerik Türkçe şifrelerden oluşur ancak İngilizce şifreler de dahil edilmiştir. Bu wordlist, WiFi şifreleri için oluşturulmuştur ve araştırma, güvenlik testleri ve diğer amaçlar için kullanılabilir. Dosya boyutu çok büyük olduğu için drive yükledim. Burdaki wordlistin sadece önizlemesidir.
